# PersianGuard Compatible Fonts

The following fonts are included in the PersianGuard compatible-font whitelist:

- `Arial.TTF`
- `B Roya.ttf`
- `B Titr.ttf`
- `Bahij Nazanin.ttf`
- `DejaVuSans-Bold.ttf`
- `DejaVuSans.ttf`
- `DejaVuSansMono-Bold.ttf`
- `DejaVuSansMono.ttf`
- `FreeMono.ttf`
- `FreeMonoBold.ttf`
- `FreeMonoBoldOblique.ttf`
- `FreeMonoOblique.ttf`
- `FreeSans.ttf`
- `FreeSansBold.ttf`
- `FreeSansBoldOblique.ttf`
- `FreeSansOblique.ttf`
- `FreeSerif.ttf`
- `FreeSerifBold.ttf`
- `IranNastaliq.ttf`
- `Vazir.ttf`
- `opens___.ttf`
- `tahoma.ttf`
- `unifont.otf`
- `unifont_jp.otf`

Use these fonts for whitelist-constrained PersianGuard rendering. Font licensing remains with each font's respective author or distributor; verify the applicable license before redistribution or commercial use.
